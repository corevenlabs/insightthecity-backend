Queremos que todas las personas puedan usar ITC Club, incluidas las personas con discapacidad.

# Nuestro compromiso

Trabajamos para que la app cumpla las Pautas de Accesibilidad para el Contenido Web (**WCAG) 2.1, nivel AA**, aplicadas a apps móviles.

# Lo que hacemos

- Etiquetas para lectores de pantalla (VoiceOver y TalkBack) en botones e íconos.
- Contraste de color suficiente en textos y controles.
- Compatibilidad con el tamaño de texto del sistema.
- Formularios con etiquetas visibles y mensajes de error anunciados.
